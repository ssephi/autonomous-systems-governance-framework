# Security Policy

This repository contains governance documentation rather than software.

While the framework itself cannot be exploited at runtime, security concerns relating to the content of the framework are taken seriously.

## Reporting

For non-sensitive issues, please open a GitHub Issue.

For sensitive concerns, please use the repository's [Private Vulnerability Reporting](../../security/advisories/new) feature, or contact the maintainer through GitHub.

## Scope

Examples of issues that may be in scope include:

- Guidance that could reasonably result in unsafe implementation
- Governance contradictions that weaken controls
- Repository integrity concerns
- Accidental disclosure of sensitive information within the repository

Examples that are not in scope include:

- Vulnerabilities in software that adopts this framework
- Vulnerabilities in third-party products
- General governance disagreements or design preferences

General discussion and improvement proposals should be raised through GitHub Issues.

## Response

This is a maintainer-led project.

Reports are reviewed on a best-effort basis and no formal response SLA is provided.
